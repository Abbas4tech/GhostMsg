# Type-Safe API Layer with Zod OpenAPI, openapi-fetch, Scalar, and React Query

We use `@asteasolutions/zod-to-openapi` to maintain a single-source-of-truth OpenAPI 3.1 specification directly from our Zod schemas in `src/lib/openapi.ts`. Static TypeScript definitions are auto-generated via `openapi-typescript` (`npm run typegen`), powering a lightweight, zero-boilerplate SDK via `openapi-fetch` and TanStack React Query (`@tanstack/react-query`). Interactive API documentation is hosted via Scalar at `/docs` and `/api/docs`. This deprecates Axios in favor of native `fetch` with `AbortSignal`, eliminating manual request boilerplate and providing compile-time end-to-end type safety.
